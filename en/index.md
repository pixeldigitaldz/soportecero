# SoporteCero

> Soluciones directas y concisas a errores técnicos de sistemas, Linux, servidores, desarrollo web y gaming.

SoporteCero (https://soportecero.com) es una base de conocimiento técnico orientada a resolver incidencias complejas con explicaciones claras, causas raíz y comandos listos para copiar.

## Categorías Principales

- [Sistemas y Servidores](https://soportecero.com/?cat=sistemas): Solución a errores de Docker, Nginx, Linux, Proxmox, SSH, Systemd, Btrfs y almacenamiento.
- [Gaming Tech](https://soportecero.com/?cat=gaming): Diagnóstico de caídas de FPS, crashes de Proton/Wine, VKD3D, DXVK, Steam Deck, Gamescope y drivers GPU en Linux.
- [Web y Código](https://soportecero.com/?cat=web): Resolución de bugs de TypeScript, Node.js, React, Next.js, Vite, Git, CORS, bases de datos y APIs.

## Recursos de Descubrimiento para Agentes de IA

- [Catálogo de API (RFC 9727)](https://soportecero.com/.well-known/api-catalog): Descubrimiento formal de interfaces y servicios de la plataforma.
- [Manifiesto de Capacidades ARD](https://soportecero.com/.well-known/ai-catalog.json): Catálogo estandarizado de servidores MCP y habilidades de IA.
- [Tarjeta de Servidor MCP (SEP-1649)](https://soportecero.com/.well-known/mcp/server-card.json): Servidor de herramientas Model Context Protocol para consulta de guías.
- [Tarjeta de Agente A2A](https://soportecero.com/.well-known/agent-card.json): Interfaz de agente a agente para diagnóstico técnico.
- [Índice de Habilidades de Agente](https://soportecero.com/.well-known/agent-skills/index.json): Colección de habilidades técnicas para asistentes de IA.
- [Guía de Autenticación de Agentes (Auth.md)](https://soportecero.com/auth.md): Especificación de registro y autenticación para agentes.
- [Directorio Completo de Guías](https://soportecero.com/llms-full.txt): Listado detallado de todos los artículos técnicos disponibles.

## Formatos y Enlaces Alternativos
